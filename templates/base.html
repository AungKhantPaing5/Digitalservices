  1. Install Happ - Proxy Utility from the official App Store / Google Play.
  2. Sign into DigitalServices and open your dashboard.
  3. Tap Copy Subscription Link.
  4. Open Happ and tap + (Add).
  5. Choose Import from Clipboard / Add Subscription.
  6. Allow paste permission and load the server list.
  7. Select the server and tap Connect; approve the system VPN prompt.
  8. For renewal, update the existing subscription instead of sharing your private link.
